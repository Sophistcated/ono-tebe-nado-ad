# Оно тебе надо

Учебная страница аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/Sophistcated/ono-tebe-nado-ad

Статичная вёрстка по макету Яндекс Практикума: семантический HTML, CSS Grid и Flexbox, локальные шрифты Raleway и изображения. Макет рассчитан на ширину 1100 px.

Для просмотра откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.
